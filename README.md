# Employee Dashboard

## Project Overview

This project analyzes employee data using Microsoft Excel and presents key insights through an interactive dashboard.

## Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- Charts
- Data Analysis
- Data Visualization

## Analysis Performed

- Employee distribution analysis
- Department-wise analysis
- Salary analysis
- Employee performance analysis
- Employee demographics analysis
- KPI and dashboard creation
